[size=5][b]Architecture Overview[/b][/size]

PrintScreen V4 is a zero-integration SKSE plugin. It does [b]not[/b] hook the game's renderer or intercept swap chains. Instead, it uses the Windows [b]Desktop Duplication API[/b] ([font=Courier New]IDXGIOutputDuplication[/font]) to capture frames directly from the display output.

[size=4][b]Design Philosophy[/b][/size]

[list]
[*][b]No game integration:[/b] Works regardless of rendering API, ENB, ReShade, or overlay
[*][b]GPU-first:[/b] D3D11 textures flow through GPU paths where possible (video encoding, scaling)
[*][b]Async worker thread:[/b] Capture runs on a dedicated thread so the game thread is never blocked
[*][b]Cooperative cancellation:[/b] Long-running operations (GIF encoding, video capture) check a cancellation token
[/list]
[size=4][b]Data Flow[/b][/size]

[code]Desktop Duplication API
        |
        v
+-----------------+
|  FrameAcquirer  |  <- Owns D3D11 device + DXGI duplication
|   (src/capture) |
+--------+--------+
         | ID3D11Texture2D (GPU texture)
         v
+-----------------+     +------------------+
|   GPUScaler     |     |   VideoCapture   |
| (GPU downscale) |     |  (H.264 encoder) |
+--------+--------+     +------------------+
         |
         v (optional)
+-----------------+
| ScratchImage    |  <- CPU staging copy (stills, GIF, APNG)
| (DirectXTex)    |
+--------+--------+
         |
    +----+----+--------+--------+
    v         v        v        v
 StillEncoder GifEncoder ApngEncoder
 (PNG/JPEG/   (GIF)    (APNG)
  BMP/TIFF/
  DDS)
[/code]

[size=5][b]Capture Pipeline[/b][/size]

[size=4][b]1. CaptureSession (Orchestrator)[/b][/size]

[code]class CaptureSession {
public:
    enum class StartResult {
        Accepted,        // Capture started
        AlreadyRunning,  // Worker thread busy
        InvalidState,    // Unexpected state machine state
        BusyCancelled    // Previous capture cancelled, ready for retry
    };

    StartResult Start(CaptureRequest request,
                      CompletionCallback onComplete,
                      AcquisitionCallback onAcquisitionComplete);
    void RequestCancel();
    std::string GetResult();  // Papyrus polling: "Ready", "Starting", "Running", "CALLBACK_SUCCESS", ...
};
[/code]

[b]State Machine:[/b]

[code]Idle -> Starting -> Running -> Done -> (consumed) -> Idle
         |           |
         +-----------+ (RequestCancel -> CALLBACK_CANCELLED)
[/code]

[size=4][b]2. FrameAcquirer (Desktop Duplication)[/b][/size]

[code]class FrameAcquirer {
    HRESULT Initialize();                          // Create D3D11 device + IDXGIOutputDuplication
    HRESULT AcquireFrame(DirectX::ScratchImage& out);       // CPU path
    HRESULT AcquireFrameGPU(ID3D11Texture2D*& out, uint32_t& w, uint32_t& h);  // GPU path
};
[/code]

[b]Critical:[/b] The D3D11 device [b]must[/b] be created with [font=Courier New]D3D11_CREATE_DEVICE_VIDEO_SUPPORT[/font] for hardware video encoding to work. Without this flag, Media Foundation hardware MFTs silently refuse to bind.

[size=4][b]3. GPUScaler (Resolution Scaling)[/b][/size]

Implements bilinear downscaling via a fullscreen render quad:
[list]
[*]No vertex buffer (generates quad from [font=Courier New]SV_VertexID[/font])
[*]Letterbox-preserving aspect ratio scaling
[*]Output: [font=Courier New]DXGI_FORMAT_B8G8R8A8_UNORM[/font] with [font=Courier New]D3D11_BIND_SHADER_RESOURCE | D3D11_BIND_RENDER_TARGET[/font]
[*]Shaders compiled at runtime via [font=Courier New]D3DCompile[/font] (no external [font=Courier New].cso[/font] files)
[/list]
[size=4][b]4. CaptureRequest (Parameter Struct)[/b][/size]

[size=4][b]Rate Control Mapping[/b][/size]

[code]UINT32 EncoderRateControlConstant(RateControlMode mode) {
    switch (mode) {
        case CBR: return eAVEncCommonRateControlMode_CBR;
        case VBR: return eAVEncCommonRateControlMode_UnconstrainedVBR;
        case CQP: return eAVEncCommonRateControlMode_Quality;

[size=4][b]Timestamp Math[/b][/size]

To minimize accumulated rounding error over long captures:

[code]// Correct (minimizes drift):
LONGLONG timeHns = (frameIndex * kHnsPerSecond) / fps;

// Incorrect (accumulates rounding error):
// LONGLONG timeHns = frameIndex * (kHnsPerSecond / fps);
[/code]

Where [font=Courier New]kHnsPerSecond = 10'000'000LL[/font] (100-nanosecond units).

[size=4][b]Thread Safety[/b][/size]

[list]
[*][font=Courier New]Initialize()[/font], [font=Courier New]EncodeFrame()[/font], [font=Courier New]Finalize()[/font] must all be called from the [b]same thread[/b] (the CaptureSession worker thread)
[*]D3D11 multithread protection is [b]enforced[/b] in [font=Courier New]Initialize()[/font]:
[/list]  [code]  ComPtr<ID3D10Multithread> mt;
  device->QueryInterface(IID_PPV_ARGS(&mt));
  mt->SetMultithreadProtected(TRUE);
  [/code]

[size=4][b]Streaming vs Buffered[/b][/size]

Unlike GIF/APNG (which buffer all frames in memory then encode), VideoCapture:
[list=1]
[*]Encodes each frame immediately via [font=Courier New]IMFSinkWriter::WriteSample()[/font]
[*]Streams to disk  -  no full in-memory frame buffer
[*]Memory usage is constant regardless of duration
[/list]
[size=4][b]MKV Status[/b][/size]

The [font=Courier New]VideoContainer::MKV[/font] enum exists but falls back to MP4 with a log warning. Media Foundation's built-in sink writer does not support Matroska. Future versions may add FFmpeg integration (LGPL considerations apply).

[size=5][b]UI Controller[/b][/size]

[size=4][b]Primary Mechanism: [font=Courier New]RE::UI::ShowMenus()[/font][/b][/size]

The UI controller uses the same bool that the [font=Courier New]tm[/font] console command toggles:

[code]bool UIController::HideAll() {
    auto* ui = RE::UI::GetSingleton();
    savedShowMenus_ = ui->IsShowingMenus();
    ui->ShowMenus(false);   // Single bool write, thread-safe
    hidden_ = true;
}

bool UIController::RestoreAll() {
    auto* ui = RE::UI::GetSingleton();
    ui->ShowMenus(savedShowMenus_);  // Restore previous state
    hidden_ = false;
}
[/code]

[b]Thread safety:[/b] [font=Courier New]ShowMenus(bool)[/font] is a plain bool write checked early in the engine render loop. It is safe to call from the capture worker thread without SKSE task marshalling.

[size=4][b]Granular Scaleform Helpers (Deprecated)[/b][/size]

The class retains per-element visibility helpers for selective UI hiding:
[list]
[*][font=Courier New]SetHUDAlpha()[/font], [font=Courier New]HideHUD()[/font], [font=Courier New]ShowHUD()[/font]
[*][font=Courier New]SetSubtitlesVisible()[/font], [font=Courier New]SetNPCNamesVisible()[/font], etc.
[/list]
[b]These require game-thread execution[/b] (via [font=Courier New]SKSE::GetTaskInterface()->AddTask()[/font]) because GFx is not thread-safe.

[size=4][b]Async Wrappers[/b][/size]

[code]void UIController::HideAllAsync()    { HideAll(); }    // Inline, thread-safe

[/code]

Kept for API consistency when called from worker threads.

[size=4][b]Implementation[/b][/size]

[code]// logger.h

The worker thread:
[list=1]
[*]Acquires frames from Desktop Duplication
[*]Runs encoding (CPU-bound for stills/GIF/APNG, GPU-bound for video)
[*]Calls completion callback
[*]Sets result state for Papyrus polling

[size=4][b]Cancellation Token[/b][/size]

Long-running operations periodically check the token. Frame acquirer checks before each [font=Courier New]AcquireNextFrame()[/font] call.

| Component | Thread | Notes |
|-----------|--------|-------|
| [font=Courier New]CaptureSession::Start()[/font] | Any | Spawns worker, returns immediately |
| [font=Courier New]CaptureSession::GetResult()[/font] | Any (Papyrus) | Poll from game thread |
| [font=Courier New]UIController::HideAll()[/font] | Any | Bool write is atomic |

[size=5][b]Known Issues & Limitations[/b][/size]

[size=4][b]Papyrus Script Compilation[/b][/size]

All [font=Courier New].psc[/font] scripts currently fail to compile without:
[list]
[*]PapyrusUtil SE (JsonUtil, StorageUtil)
[*]JContainers SE (JIntMap)
[*]SKSE extended compiler flags ([font=Courier New]Hidden[/font] property support)
[/list]
[b]Status:[/b] Scripts may be shipped as pre-compiled [font=Courier New].pex[/font] files, or dependencies must be installed.

[size=4][b]Video Capture Edge Cases[/b][/size]

[list=1]
[*][b]MKV container[/b]  -  Not implemented. Falls back to MP4 with warning.
[*][b]CQP + Bitrate[/b]  -  Bitrate is ignored when [font=Courier New]rateControl=CQP[/font]. Quality value is used instead.
[*][b]Hardware encoder unavailability[/b]  -  Falls back to software. May be slow at high resolutions.
[*][b]Abrort without Finalize[/b]  -  MP4 file is unplayable (no [font=Courier New]moov[/font] atom). Use [font=Courier New]Abort()[/font] on game crash/force quit.
[*][b]D3D11 video support flag[/b]  -  If the device was created without [font=Courier New]D3D11_CREATE_DEVICE_VIDEO_SUPPORT[/font], hardware encoding silently fails.
[/list]
[size=4][b]Resolution Scaling[/b][/size]

[font=Courier New]GPUScaler[/font] uses bilinear filtering. For highest quality downscaling (e.g., 4K->1080p), Lanczos or bicubic would be better but require more complex shader code.

[size=4][b]Memory Usage[/b][/size]

[list]
[*][b]Stills:[/b] One frame (~8MB for 1080p RGBA)
[*][b]GIF/APNG:[/b] All frames buffered in memory before encoding
[/list]15s @ 30fps @ 1080p = ~450 frames x ~8MB = [b]~3.6GB[/b] (sub-item)
Duration clamped to 15s to prevent excessive memory use (sub-item)
[list]
[*][b]H.264:[/b] Constant memory  -  frames encoded and streamed to disk immediately
[/list]
[size=4][b]Desktop Duplication Limitations[/b][/size]

[list]
[*]Cannot capture content protected by HDCP/DRM
[*]Captures the entire desktop, not just the game window (so multi-monitor setups capture all monitors unless cropped)
[*]Requires Windows 8.1+ ( DXGI 1.2+)
[/list]
[size=4][b]UI Hiding[/b][/size]

[list]
[*]Uses [font=Courier New]RE::UI::ShowMenus(bool)[/font]  -  same as [font=Courier New]tm[/font] console command
[*]Hides [b]all[/b] UI: HUD, compass, crosshair, quest markers, mod HUDs, menus
[*]Cannot selectively hide individual elements without Scaleform API (which requires game-thread execution)
[/list]
